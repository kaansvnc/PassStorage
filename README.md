# PassStorage

**Şifreleriniz yalnızca sizde.** PassStorage, kullanıcı adlarınızı, şifrelerinizi, notlarınızı ve dosyalarınızı
yalnızca kendi bilgisayarınızda, şifreli olarak saklayan sade bir Windows şifre kasasıdır.
Bulut yok, hesap açma yok, takip yok.

*English below.*

## İndir
En son sürüm için sağdaki **[Releases](https://github.com/kaansvnc/PassStorage/releases/latest)**
bölümünden `PassStorage-Setup-X.Y.Z.exe` dosyasını indirin.

- Windows 10 / 11 (64 bit)
- Ücretsiz, çevrimdışı çalışır
- Veriler Windows şifrelemesi (DPAPI) ile `%APPDATA%\PassStorage` klasöründe saklanır; internete hiçbir şey gönderilmez.

Kurulum dosyası kod imzalı olmadığından ilk çalıştırmada Windows SmartScreen uyarısı çıkabilir:
**Ek bilgi → Yine de çalıştır**.

Web sitesi ve iletişim: [www.omerkaansevinc.com](https://www.omerkaansevinc.com/)

Bu depo yalnızca kurulum dosyalarının dağıtımı içindir; kaynak kod burada yer almaz.

## English

**Your passwords stay with you.** PassStorage is a clean, simple Windows password vault that keeps your usernames,
passwords, notes and files encrypted on your own computer only. No cloud, no sign-up, no tracking.

Download `PassStorage-Setup-X.Y.Z.exe` from the
**[latest release](https://github.com/kaansvnc/PassStorage/releases/latest)**.

- Windows 10 / 11 (64-bit), free, works offline
- Data is encrypted with Windows DPAPI and stored in `%APPDATA%\PassStorage`; nothing is sent to the internet.

The installer is not code-signed, so Windows SmartScreen may warn on first run: **More info → Run anyway**.

This repository only distributes installers; the source code is not published here.
